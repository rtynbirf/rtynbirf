# 🐝 CELLS — навыки и инструменты, перенесённые в репо

> Манифест: полимат = мультиагент. Каждый инструмент = клетка роя с одной функцией.
> Всё ниже — реально работавшие в сессии 2026-11-08 механизмы, а не концепты.
> Статус: **LIVE** = работает автономно · **READY** = готов к запуску руками

| # | Клетка | Статус | Что делает | Как запустить |
|---|---|---|---|---|
| 01 | **swarm-sync** (сверка со средой) | 🟢 LIVE | Ежедневно сама собирает статистику всех репо (вкл. приватные) через живой GitHub API, регенерирует секцию README, коммитит только при реальных изменениях от `swarm-sync[bot]` | Автоматически (cron 03:17 UTC) или Actions → Run workflow |
| 02 | **repo-xray** (рентген аккаунта) | 🟡 READY | Полный разбор аккаунта: все репо, языки по байтам, число коммитов на репо (через Link-пагинацию), JSON-выгрузка | `GITHUB_TOKEN=... python cell-02-repo-xray.py > xray.json` |
| 03 | **layout-render** (метод Reve) | 🟡 READY | Layout-first генерация: структурный JSON → HTML/CSS-скелет → скриншот → рендер по промпту из layout. Пример сцены: `example-layout.json` | `python cell-03-layout-shot.py` (нужен playwright) + любой text-to-image по промпту из JSON |
| 04 | **report-mirror** (зеркало отчётов) | 🟡 READY | Выкачивает чужой техотчёт: HTML → полный Markdown (заголовки, таблицы, код, ссылки) + все ассеты + реестр URL | `python cell-04-report-mirror.py < html > report.md` |
| 05 | **pipeline-merge** (склейка) | 🟡 READY | Склеивает шаги пайплайна в одну наглядную картинку (скелет + рендер с подписями) | `python cell-03-pipeline-merge.py` |

## Что НЕ переносится (честно)

- Веса и внутренности модели-исполнителя — не артефакт, переносятся **методы**.
- Секреты: клетка 01 берёт токен из `SWARM_TOKEN` (Actions secret), ни в одном файле репо токенов нет.

## Принцип клетки

1. Сама формулирует задачу из состояния среды (API = среда).
2. Сама вычисляет (stdlib-only, без зависимостей — переносимо).
3. Сама решает: менять или нет (анти-шум, анти-галлюцинация: числа только из API).
4. Сама связывает: результат прямо в витрину профиля.
