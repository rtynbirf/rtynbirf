## КАРТИНКИ (класс «ПРОПАЛИ КАРТИНКИ» — запрещено повторять)
4. Бинарные файлы (PNG/JPEG/GIF) пишутся ТОЛЬКО через `POST /git/blobs {"content": "<base64>", "encoding": "base64"}` → tree ссылается на blob sha. Поле `content` в tree-API хранит строку КАК ЕСТЬ: base64-текст в `.png` = битая картинка (raw отдаёт `text/plain`, браузер показывает alt вместо изображения).
5. SVG — текст, ему допустим `content`. Но после записи ЛЮБОЙ картинки — проверка: raw → `content-type image/png|image/svg+xml` и магия `\x89PNG\r\n\x1a\n` в первых 8 байтах. Без проверки запись картинки считается незавершённой.
6. Счётчик `<img` в README после твоей правки не должен уменьшиться. Картинку заменил — замени целиком (ссылку-обёртку `<a href=репо><img …></a>` не раздевать: картинка без ссылки-обёртки теряет навигацию).

## WORKFLOWS
7. В YAML-шаблонах не использовать Python `.format()` — он схлопывает `${{ }}` в `{ }`, и env становится литералом `${ github.repository }`. Только `.replace("{num}", …)` или сборка без фигурных коллизий.
8. После деплоя workflow — прочитать файл обратно и убедиться, что `${{ github.repository }}` стоит литерально, `fetch-depth: 0`, триггеры = расписание + workflow_dispatch.
9. push-триггер рядом с самописцем не добавлять: на каждый push в доме отвечает РЕВО АВТОПИЛОТ — один гейт на класс события. Гонка самозаписей на README уже рвала ветку.

## САМОЗАПИСЬ (зуб A-HUSH)
10. Порядок: `git add -A` → commit → **push первым**; при отказе — `git fetch origin main` + `git pull --rebase=merges origin main` → повтор (3 попытки). На shallow-клоне `git rebase origin/main` падает — старый код при этом вообще не пробовал push. fetch-depth: 0 всегда.
11. Регенерация артефактов — на свежем main: fetch → `reset --hard origin/main` → пересоздать → commit → push (так делает РЕВО АВТОПИЛОТ).
12. Коммит-сообщение: что сделано + класс дефекта (если чин) + `REVE=РЕВО`.

## АВТОМАТЫ И ЗАМЕРЫ
13. Дрейф — по содержанию (файловая система, state-файл исключён), не по летучим счётчикам: `n_commits` растёт каждый цикл самозаписи — иначе вечный ДРЕЙФ→КУЗНЯ-самоцикл с коммитом каждый час.
14. `git ls-files` не видит некоммиченные файлы — истина файловой системы (os.walk).
15. Гейт проверяет МАГИЮ ФОРМАТА (первые 8 байт PNG), не размер: проверка «файл >1000 Б» пропустила base64-текст во весь флот.
16. Музейные тела: Actions отключены, напрямую писать нельзя — их держит центральный обходчик (unarchive → лечение → archive), состояние МУЗЕЙ.

30. **КАНОН = НЕПРОИЗВОДНОЕ.** В канон идёт только то, чего нет в дереве и чего нельзя

31. **СВОД И ХВОСТ.** Журнал делится на свод-префикс (компиляция уроков: один класс —

    читает свод целиком + хвост истории; вся история — только verify и приёмка.

32. **ОБРАЗЕЦ СИЛЬНЕЕ КАПСА.** Правило несёт класс косяка или мини-образец «как надо»;

33. **ФОРМА, НЕ СПИСОК.** Ограничение задаётся формой — грамматикой, схемой, тестом,

    Запрет без формы — не запрет, а пожелание.
34. **ПРОГРЕССИВНОЕ РАСКРЫТИЕ.** Инструкции грузятся слоями: ближайший AGENTS.md

35. **РЕЦЕДАЦИЯ ЯКОРЯ.** Цель такта перечитывается из манифеста волны (TODO,
