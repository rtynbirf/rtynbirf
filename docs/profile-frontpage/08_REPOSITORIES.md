# Карта репозиториев

Группировка ниже — навигационная гипотеза, а не доказательство формальной зависимости между всеми репозиториями.

| Кластер | Назначение | Точки входа |
|---|---|---|
| OS / Sovereign Systems | Локальная вычислительная среда | `polymath-os` |
| Offline Media | Офлайн-медиа и интерфейсы | `singulyar` |
| Swarm / Runtime | Автономные узлы и протоколы | `cell-swarm`, `runtime-protocol` |
| Knowledge / Atlases | Карты практик и отношений | `global-practice-atlas`, `relomat` |
| Voice / Media Models | Голосовые и медиа-модели | `voice-atlas-llm` |
| Shared Foundations | Общие основания | `commons`, `lfs-core` |

Перед публикацией проверить существование, видимость, архивность, default branch, live demo, лицензию и актуальность описания каждого флагмана. Полная проверка всех перечисленных репозиториев не выполнялась в рамках этого внешнего аудита.
