# Безопасная миграция

1. Клонировать `rtynbirf/rtynbirf`; проверить чистое рабочее дерево.
2. Зафиксировать HEAD и default branch.
3. Сохранить текущий README как baseline.
4. Сверить текущие ссылки и изображения.
5. Создать отдельную ветку `docs/profile-frontpage-v1`.
6. Подготовить diff только для README и нового каталога документации.
7. Не удалять существующие файлы и артефакты.
8. Запустить валидатор и проверить GitHub Preview.
9. Пройти критерии приёмки.
10. Публиковать через отдельный коммит/PR после согласования.

Rollback: вернуть baseline отдельным revert-коммитом. Не force-push. Не менять default branch. Не перезаписывать генерируемые файлы вручную.
