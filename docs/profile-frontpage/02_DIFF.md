# Дифференциальная матрица

| Область | Сейчас | Цель | Приоритет |
|---|---|---|---|
| Идентичность | Сильная, но несколько формулировок | Одно точное определение | P1 |
| Первый экран | Много конкурирующих блоков | Название, определение, быстрые маршруты | P0 |
| Навигация | Несколько карт и перечней | Единая карта входа | P0 |
| Флагманы | Длинный перечень клеток | 5–7 точек входа, полный каталог отдельно | P1 |
| Телеметрия | Несколько счётчиков | Один источник на метрику + timestamp | P0 |
| Доказательства | Ссылки распределены | Claim → Evidence → Method → Result → Scope | P0 |
| Статусы | Локальные обозначения | Раздельные статусы реализации и проверки | P1 |
| Архитектура | Карты и метафоры | Краткая схема + отдельное объяснение | P1 |
| Образность | Сильная, местами конкурирует с фактами | Сохранить как авторский слой | P1 |
| История | Встроена в README | Отдельная хроника/отчёты | P2 |
| Полный каталог | Встроен в профиль | Отдельный каталог | P1 |
| Доступность | Не проверена полностью | Alt, заголовки, текстовые альтернативы | P1 |

P0 блокирует публикацию. P1 — первая волна. P2 — последующее улучшение.

Не является целью: переписывание всех репозиториев, удаление авторского языка, изменение исходного кода флагманов или ручная правка генерируемых данных.
