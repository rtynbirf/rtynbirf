# Критерии приёмки

## Содержание
- [ ] Назначение понятно без чтения истории.
- [ ] Есть 3–5 маршрутов входа.
- [ ] На первом уровне не более 5–7 флагманов.
- [ ] Полный каталог вынесен отдельно.
- [ ] Авторская идентичность сохранена.
- [ ] Метафора не подменяет техническое определение.

## Достоверность
- [ ] Нет конфликтующих чисел без объяснения.
- [ ] У динамических метрик есть источник, единица, timestamp и метод.
- [ ] Runtime tests отделены от claim checks/self-tests.
- [ ] Готовые данные отделены от конвейера и плана.
- [ ] Существенные утверждения имеют свидетельства и область применимости.

## Навигация и доступность
- [ ] Все локальные ссылки существуют.
- [ ] Все внешние ссылки проверены вручную.
- [ ] Один H1, последовательные заголовки.
- [ ] Изображения имеют alt.
- [ ] Смысл не зависит только от цвета.
- [ ] README понятен без картинок.

## Безопасность
- [ ] Baseline сохранён.
- [ ] Diff проверен.
- [ ] Старые документы не удалены.
- [ ] Нет секретов.
- [ ] Rollback готов.
- [ ] Публикация согласована.

## Сценарные тесты
T1: за 10 секунд понятно, что это.  
T2: за 30 секунд найден нужный проект.  
T3: за 2 минуты понятны основные направления.  
T4: найдено свидетельство к существенному утверждению.  
T5: различимы факт, эксперимент и план.  
T6: витрина открывается.  
T7: мобильная версия сохраняет структуру.

Итог: PASS / CONDITIONAL_PASS / FAIL / NOT_TESTED. Средний балл не компенсирует блокирующий дефект.
